## Decisions that need your call

### F1 — Strict actor model on every event (G1)
Every event row carries: `actor_type` (user / agent / platform / external), `actor_id` (user ID / model-call ID / component / integration ID), `actor_role` (viewer, submitter, approver, platform_admin / diagnoser, critic / intake, executor, verifier, … / monitoring, git, cicd, …), `on_behalf_of`, `auth_method`, `session_id`, `request_id`, `reason` (required for cancel, take-over, reject, self-approval, severity change, disable user, config change, resolve). The API fills it from the logged-in caller; a request body can never set it. A database CHECK makes "only a user with the approver role can approve" a hard rule (SC-04).

### F2 — Platform audit stream, hash chain, audit API (G2, G3)

Admin endpoints: `GET /v1/audit/events` (filters) and `GET /v1/audit/verify` (re-checks the chain). Each audit query is itself logged.

### F3 — User management (G4, G21)
- Endpoints (platform admin): create (returns a one-time password, must change at first login), list, read, update, **disable / enable (no delete; disable revokes sessions)**, unlock, password reset. Every user: `GET /v1/users/me`, change own password.
- First admin: CLI `ai-sre admin bootstrap`, only when no admin exists.
- SSO mode: admin pre-creates the user with the SSO subject; an unknown subject is refused (keeps "no self-signup"). Endpoints for the CLI device-code flow and OIDC callback.
- **Question:** SC-04 says a platform admin cannot approve. Recommendation: the admin flag sits on a **separate admin account**, so a person who is also on call approves with their normal account.

### F5 — Configuration: where it lives and who changes it (G6, G17)

### F7 — Fix approval vs PR merge (G12)
A2 says "the merge is the approval"; A5 says the platform signs the approval. Recommendation: the **signed approval is the record**; the merge must match it (merger maps to an eligible non-author user via a new `user_identity` table; merged SHA = approved SHA; mismatch → escalate). Merge detected by polling the PR (no new inbound endpoint). Final design in Layer 11 (Rinisha).
